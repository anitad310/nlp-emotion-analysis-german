# Distributional Analysis of the Emotions "Freude" and "Wut" in German Corpora

## Project Overview

This academic project investigates the linguistic representation of the German emotion concepts **"Freude" (joy)** and **"Wut" (anger)** using corpus-linguistic and computational methods.

The analysis is based on six subcorpora from the **DWDS (Digitales Wörterbuch der deutschen Sprache)** and compares newspaper, web/blog, and DTA corpus data.

## Methods

* **Data preprocessing** – cleaning, tokenization and German stopword removal
* **Collocation analysis** – identifying frequent words occurring near the target concepts
* **Word2Vec** – exploring distributional semantic relationships
* **K-Means clustering & PCA** – grouping and visualising semantic patterns
* **Dependency parsing** – analysing syntactic roles and relationships using spaCy

## Corpora

The analysis includes:

* Berliner Zeitung – *Freude* / *Wut*
* Webkorpora & Blogs – *Freude* / *Wut*
* DTA Metakorpus – *Freude* / *Wut*
